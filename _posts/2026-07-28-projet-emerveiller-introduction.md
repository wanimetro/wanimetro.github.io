# Projet Émerveiller

> **Du mouvement à l'émotion.**  

---

## 🌟 About

안녕하세요. 오소원입니다.

**Projet Émerveiller**는 Unity를 기반으로 인터랙티브 미디어와 실감형 콘텐츠를 공부하고 기록하는 개인 프로젝트입니다.

단순히 기능을 구현하는 것을 넘어, 기술을 통해 사람들에게 새로운 경험과 감동을 전달하는 인터랙티브 콘텐츠를 만드는 것이 저의 목표입니다.

이 프로젝트는 그 목표를 향해 배우고, 구현하고, 기록하며 성장하는 모든 과정을 담아갈 예정입니다.

---

## 🌟 Vision

Projet Émerveiller는 더 큰 인터랙티브 프로젝트를 만들기 위한 기본기를 다지는 과정입니다.

마우스 입력부터 시작해 손동작 인식, 나아가 신체 동작 인식까지 단계적으로 확장하며 입력 방식의 변화에 따라 인터랙션을 발전시키는 것을 목표로 합니다.

작은 프로젝트를 하나씩 완성해 나가며 실감형 콘텐츠 개발 역량을 꾸준히 키워나가고자 합니다.

---

## 🌟 Goal

이 프로젝트에서는 다음과 같은 기술을 단계적으로 학습합니다.

- Unity
- C#
- Input System
- Particle System
- Trail Renderer
- Shader Graph
- Lighting & Post Processing
- Audio Reactive
- Hand Tracking
- Body Interaction
- Interactive Media

배운 내용을 그대로 따라 만드는 것에서 끝내지 않고, 직접 실험하고 개선하며 저만의 방식으로 구현하는 것을 목표로 합니다.

---

## 🌟 Roadmap

이 프로젝트는 **입력(Input)의 확장**을 중심으로 진행됩니다.

```text
Mouse Interaction
        ↓
Hand Tracking
        ↓
Body Interaction
        ↓
Interactive Media
````

## 🌟 Commit Convention

```text
type(scope): message
```

| Type     | Description   |
| -------- | ------------- |
| feat     | 새로운 기능 추가     |
| fix      | 버그 수정         |
| refactor | 코드 개선         |
| docs     | 문서 및 블로그 작성   |
| style    | UI 및 시각 요소 수정 |
| test     | 기능 실험         |
| chore    | 프로젝트 설정       |
| perf     | 성능 개선         |

하나의 커밋에는 하나의 의미 있는 변경만 담는 것을 원칙으로 합니다.
