# Why I Started

이번 여름방학에는 첫 번째 실감형 프로젝트를 시작해보려고 합니다.

처음부터 거대한 게임이나 XR 프로젝트를 만드는 것이 목표는 아닙니다.

Unity를 차근차근 배우며 기술 하나를 이해하고, 직접 응용해 보고, 그 과정을 기록하는 것이 이번 프로젝트의 가장 큰 목표입니다.

이번 프로젝트에서는 결과물뿐만 아니라 **학습 과정 자체도 하나의 프로젝트**라고 생각합니다.

유튜브 강의를 따라 하는 것에서 끝나는 것이 아니라, 배운 기술을 직접 응용하고, GitHub에 기록하고, 블로그에 정리하며, 마지막에는 하나의 인터랙티브 작품으로 완성해보고자 합니다.

---

# Summer Roadmap

이번 여름방학에는 단순히 Unity 강의를 완강하는 것이 목표가 아닙니다.

하나의 기술을 배우고, 직접 구현해 보고, 작은 데모를 만든 뒤 GitHub와 블로그에 기록하는 과정을 반복하며 실력을 쌓아갈 계획입니다.

학습은 아래와 같은 순서로 진행하려고 합니다.

```text
Learn
    ↓
Practice
    ↓
Create a Small Demo
    ↓
Record on GitHub
    ↓
Write a Blog Post
    ↓
Repeat
```

강의를 그대로 따라 하는 것에서 끝내지 않고, 배운 내용을 저만의 방식으로 다시 구현해 본 뒤 다음 단계로 넘어가는 것을 원칙으로 합니다.

이 과정을 반복하며 하나씩 기술을 쌓고, 방학 마지막에는 지금까지 배운 내용을 하나의 인터랙티브 작품으로 완성하는 것이 목표입니다.

# Learning Topics

이번 여름방학 동안 아래 순서대로 학습을 진행할 예정입니다.

- Unity Basics
- C# for Unity
- Particle System
- Animation
- Shader Graph
- Lighting
- Audio
- Post Processing

각 기술을 학습한 뒤에는 작은 데모를 제작하고, GitHub와 블로그를 통해 개발 과정을 기록할 계획입니다.

---

# Final Goal

최종 목표는 지금까지 배운 기술을 하나의 실감형 프로젝트로 연결하는 것입니다.

프로젝트는 **마우스 인터랙션**부터 시작합니다.

마우스 움직임에 따라 빛과 파티클이 반응하도록 구현하고, 이후에는 노트북 카메라를 활용한 **Hand Tracking**으로 입력 방식을 확장해 볼 계획입니다.

```text
Mouse Interaction
        ↓
Visual Effects
        ↓
Hand Tracking
        ↓
Interactive Experience
```

이번 프로젝트는 거창한 결과물을 만드는 것이 아니라, 하나의 기술을 배우고 기록하며 성장하는 과정을 남기는 첫 번째 프로젝트가 되었으면 합니다.
